# 验证策略

rv32c 采用**定向指令流仿真**作为当前阶段的主要验证手段，逐级覆盖数据冒险、控制冒险与访存通路。

## 验证层次

```mermaid

    A["指令级测试"] --> B["流水线冒险测试"]
    B --> C["访存通路测试"]
    C --> D["RTL 生成检查"]
```

## 当前测试

`src/test/scala/rv32c/sim/RiscvCoreTest.scala` 中的定向测试：

| 覆盖点 | 指令序列 | 断言 |
|--------|----------|------|
| 基本 ALU 运算 | `addi x1,5` + `addi x2,7` + `add x3,x1,x2` | x3 == 12 |
| RAW 数据冒险（旁路） | 连续依赖的 ALU 指令 | 结果正确 |
| 访存写读 | `sw x3,0(x0)` + `lw x4,0(x0)` | x4 == 12，内存 0 处 == 12 |
| load-use 冒险 | `lw x4` 后紧跟 `add x6,x4,x1` | x6 == 17（停顿 1 拍后旁路） |
| 分支（控制冒险） | `beq x4,x3` 跳过下一条 | 被跳过指令未执行（x7 保持 0） |
| 跳转自循环 | `jal x0,0` | PC 停在目标，测试可观测结束 |

## 运行方式

```bash
sbt test
```

SpinalSim 默认使用 iverilog 后端（`SimConfig.withIVerilog`），结果输出到 `simWork/`。

## 待补强方向

1. **指令集全覆盖测试**：为 RV32I 每条指令生成独立的定向测试
2. **RISC-V 官方合规测试**：对接 `riscv-tests`（ISA 测试套件），加载预编译的测试镜像
3. **随机化测试**：随机指令流 + 参考模型（如 Spike ISA 模拟器）对拍
4. **波形分析**：打开 SpinalSim 波形，人工检查冒险停顿拍数与旁路行为
5. **覆盖率**：指令/分支/冒险路径的功能覆盖率统计

## 测试平台说明

`CpuTb` 将 `RiscvCore` 与两个零等待内存相连：

- 指令内存：复位后从 `resetVector` 取指
- 数据内存：字节掩码读写

两者均为组合读、同步写，方便直接观察流水线行为。接入真实 SRAM/缓存后，此测试平台可继续复用（仅需替换内存模型）。
